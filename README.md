# IPKPO LMS Portal + Supabase

Готовий проєкт для GitHub + Vercel + Supabase.

## Що вже зроблено
- React/Vite фронтенд
- Supabase auth
- Supabase таблиці:
  - profiles
  - programs
  - modules
  - applications
  - module_progress
- 8 програм
- 10 модулів на кожну програму
- погодження заявок адміном
- сертифікат PDF

## Локальний запуск
npm install
copy .env.example .env
npm run dev
